Résumé du projet
---
Conception d'un portfolio de Data Analyst spécialisé pour le secteur aéronautique, aligné sur les besoins métier d'Aéroworld.
Développement d'une vitrine professionnelle interactive intégrant démonstrations techniques, planification de projet et supports pédagogiques.

Tâches réalisées
---
**Stratégie de contenu :** Analyse des besoins du secteur aérien et structuration des compétences via une carte mentale (Miro).

**Gestion de projet :** Planification avec un diagramme de Gantt interactif dans Power BI et organisation des étapes de réalisation.

**Développement technique :** Création de dashboards Power BI dynamiques et production de supports pédagogiques (tutoriel vidéo Loom).

**Déploiement et communication :** Mise en ligne sur GitHub Pages et préparation d'une présentation orale simulée pour recruteur.

Compétences mobilisées
---
**Outils Data Visualisation :** Power BI (dataviz avancée, Gantt interactif)

**Gestion de projet :** Miro (structuration), planification Agile, cahier des charges

**Développement web :** GitHub Pages, HTML

**Communication professionnelle :** Storytelling technique, tutoriels Loom, présentation client
